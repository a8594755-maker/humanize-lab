2026-10-13 更新：多候選逐句座標下降重組（Multi-Draft Sentence Recombination）與 Codex 訂閱額度模式

本機已確認 Codex 以 ChatGPT 帳號登入，預設使用 GPT-6.1 Sol / medium（免 API Key，自動探索最新版 Codex CLI）。
新版改寫管線結合：
1. 去 AI 套話與具體日常英文句構提示（一次產生主稿與多個完整替代稿）。
2. 多尺度 Fakespot 引導目標（全文 + 雙句視窗 + 單句平均与峰值）與 Leave-One-Out 高風險句診斷。
3. 雙向語意對齊（MiniLM >= 0.68、NLI 矛盾 <= 0.65）下的逐句座標下降重組與詞彙微調。
實測兩篇不同主題 AI 文章（城市綠地、遠距工作）：
- Fakespot（引導偵測器）：從 99.99% 降至 0.14%–0.34%（接近 0%）。
- Desklib（獨立封存驗證器，不參與挑選）：從 99.98%–99.99% 降至 10.22%–16.63%（低於 20%）。
如要停止背景服務，雙擊 Stop.cmd；網頁閒置不會呼叫 Codex。
不會在額度不足或失敗時自動轉用付費 API。
已設定純文字改寫模式，真呼叫前驗證無檔案、命令、瀏覽器與外部工具。
實驗 JSON 的 rewriter 欄位記錄實際模型、回合時間與 token 用量。

以下 API 說明只適用於手動切換到「自己的 LLM API」模式。

Humanize Lab — 本機英文改寫實驗原型

啟動
1. 雙擊 Start.cmd。程式會開啟 http://127.0.0.1:8391。
2. 先貼入英文文章，按「只做本機偵測」；這不會呼叫 LLM，也不需要金鑰。
3. 填入自己的 OpenAI 相容 API Base URL（通常含 /v1）、模型 ID 與 API 金鑰。
4. 按「產生改寫並比較」。此操作會將文章送至你指定的 API，可能產生供應商費用。
5. 閱讀原文／改寫分數、第二偵測器結果、文字差異與逐輪紀錄，核對原意後再使用輸出。
6. 可匯出 JSON。關閉啟動的命令視窗（或 Ctrl+C）會停止服務及釋放本機模型。

本機已安裝環境及四個模型；若搬到別台電腦，先以 PowerShell 執行 Setup.ps1。
不必訓練或 fine-tune。Setup 下載的是已訓練權重，約 2.9 GB，加上 Python 套件需額外空間。
這台電腦的虛擬環境共用既有 PyTorch；搬移後請重新建立環境。

目前支援
- 80–2,000 個英文單字。
- HTTPS 的 Chat Completions 相容服務；HTTP 只允許 localhost / 127.0.0.1 / ::1。
- 最多 3 輪，每輪 4 個候選；一輪未改善即提早停止。
- Fakespot 引導、Desklib 最後驗證；後者不影響候選選擇。
- 數字、引用、直接引文、使用者指定文字、篇幅比對；MiniLM 相似度與 NLI 矛盾检查。
- 原文備份、回溯、停止新增 API 請求、JSON 匯出。

金鑰與資料
- 金鑰不寫入設定檔、localStorage 或報告；送出工作後介面的金鑰欄位會清空。
- 程式未記錄 API request/response body；錯誤只顯示狀態，不回傳供應商可能包含敏感資料的正文。
- 本機工作紀錄暫存在記憶體（最多 12 次）；「清除本次紀錄」可刪除，關閉服務全部消失。
- 點選「匯出完整 JSON」才由瀏覽器下載文章與實驗紀錄；不包含 API 金鑰。
- 停止按鈕無法收回已送至供應商的请求；目前請求或本機計算結束後停止新增工作。

分數解讀
- 分數是未校準模型輸出，越低代表該模型認為越不像 AI。
- 不是「由 AI 撰寫的真實機率」，也不是「AI 參與字數百分比」。
- 沒有保證通過所有偵測器。第二偵測器可能反而升高，介面會顯示。
- 所有候選不合格，或沒有足夠改善時，輸出原文。
- 品質門檻是原型啟發式設定，沒有經目標課程資料校準。語意模型不能保證事實一致。
- 單句切分與引用保護仍有限制；專有名詞及關鍵句可填入「指定保留文字」。

驗證
- test_core.py：品質失敗、回溯、停止、API 失敗、金鑰不回顯、同源限制等控制流程測試。
- smoke_local.py：真實本機偵測／語意模型，加本機 HTTP 測試替身提供固定改寫。
- verification.json：以上 smoke 的實際證據。外部 LLM API 尚未使用真實金鑰測試。
- 執行方式：.venv\Scripts\python.exe -X utf8 -m pytest test_core.py -q
- 重跑 smoke：.venv\Scripts\python.exe -X utf8 smoke_local.py

限制
- 目前是完整文章候選排序，並非 Adversarial Paraphrasing 論文的逐 token 引導解碼。
- 僅支援文字型 Chat Completions 回應，不支援只提供 Responses、Anthropic 原生 Messages 或特殊授權格式的服務。
- 不自動重試 API，避免意外重複費用。
- 使用者尚未填寫 API 金鑰，因此不能把本次測試視為真實 API 改寫成功率研究。
